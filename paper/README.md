# JOSS paper

`paper.md` and `paper.bib` follow the current JOSS structure. Automated checks
enforce the 750–1750 word body limit, required section headings, and bibliography
keys.

Before submission, replace author/affiliation/ORCID placeholders, funding and
conflict statements, repository URLs, research-impact placeholders, and the AI
disclosure with author-reviewed facts. Recheck the then-current JOSS author
guidance rather than assuming the 2026 template is unchanged.

For a local visual preview, use the official Open Journals paper tooling or a
compatible Pandoc/JOSS Docker image. Generated PDFs are excluded from version
control; JOSS builds the authoritative review PDF.
