# Security policy

## Supported versions

Only the latest tagged release receives security fixes during the pre-1.0
period.

## Reporting a vulnerability

Do not disclose vulnerabilities that could endanger aircraft, operators, or
subjects in a public issue. Use the repository's **Security → Report a
vulnerability** form and include concise reproduction steps, affected versions,
and impact. If private vulnerability reporting is unavailable, contact the
repository owner through GitHub without publishing technical details.

The maintainer aims to acknowledge reports within seven days and will coordinate
disclosure after a fix or mitigation is available. This target is not an SLA.

Private vulnerability reporting should be enabled in repository settings before
the project solicits operational deployments.
